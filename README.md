### 📌 项目简介
这是一个使用 Unity 开发的 FPS Demo，重点展示射击手感、输入系统以及武器设计。

### 🎮 核心内容
- 键鼠 / 手柄双输入 + 热切换
- 手柄适配，包括辅助瞄准（减速+转向辅助），可供玩家调整的死区，响应曲线，转向加速设置
- 完整射击系统（后坐力 / GunKick / CameraKick）
- ADS 与腰射差异化子弹逻辑
- 扩散系统（射击 / 移动惩罚）
- 武器表现（Sway / Lag / Reload IK）
- 玩家移动（冲刺 / 滑铲 / 跳跃）
- 僵尸 AI（状态机 + NavMesh + 布娃娃）
- Hitbox伤害 / Hit Marker / 击杀反馈
- HUD（得分 / 连杀 / 弹药 / 受击方向）
- 对象池优化（子弹 / 音频 / 弹痕）
- 大量FPS常见的设置项
- 迷你点小球游戏

### 🛠 技术栈
Unity / C# / Animator / NavMesh

### 🚀 目标
用于展示 FPS 手感设计与系统架构能力
